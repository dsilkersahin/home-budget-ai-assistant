    SQL workspace
    Query the selected scope. Read-only, local, and bounded to 1,000 rows.
    Tables & money calculations
    transactions: id, booking_date, month, amount, currency, kind, category, person, merchant, household, source.
    source_entries: transaction_id, signed_booked, value_date, source_type, account, card_id, section, bank_tag, bonus, original_amount, original_currency, exchange_rate, filename, sheet, source_row, raw_json.
    JOIN source_entries ON source_entries.transaction_id = transactions.id
    Use DECIMAL_SUM(amount) for money; SUM / AVG / TOTAL are disabled. Amount is a positive magnitude; kind controls consumption. Imported historical entries retain workbook sheet and row provenance.
